CSV Format Requirements

The CSV file should contain the following columns:

Column Description Required
container_dir Full path to the container directory Yes
folder_kind Type of folder (Business, Documents, etc.) No
status Scan status (ingested, skipped, error) Yes
reason Reason for status (ok, no_pif_found, error message) No
pif_file Full path to the PIF file if found No
files_count Number of files in the directory No
rows Number of rows in the PIF file No
Example CSV Format:
container_dir,folder_kind,status,reason,pif_file,files_count,rows
