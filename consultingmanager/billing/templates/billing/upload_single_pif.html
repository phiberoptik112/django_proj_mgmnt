How It Works
  1. Upload PIF: Select a PIF Excel file from your computer
  2. Choose Project: Either link to an existing project or create a new one
  3. Auto-Extract: The system will automatically extract project information from the PIF
  4. Review & Edit: You'll be redirected to review and complete the extracted information
Note: The PIF file should be in standard Excel format (.xlsx or .xls). The system will attempt to automatically extract fields like project number, client name, billing contact, contract amount, and more. If data is missing or parsing fails, placeholder values will be used and you can edit them afterwards.
