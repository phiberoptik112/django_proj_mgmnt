# PIF Scanner System

The PIF (Project Information Form) Scanner system allows you to scan project directories for PIF files and maintain a database of scan results for integration with the billing system.

## Features

- **Scan Project Directories**: Automatically scan year-based project folders for PIF files
- **CSV Import**: Import scan results from CSV files generated by external scanners
- **Scheduled Scanning**: Set up periodic scans (daily, weekly, monthly)
- **Database Integration**: Link scan results to projects in the billing system
- **Search and Filter**: Find PIF files by project number, name, or status

## Usage

### 1. Access the PIF Scanner

Navigate to **Billing > PIF Scanner** in the main navigation menu.

### 2. Create a Scan Batch

1. Click **"New Scan Batch"**
2. Enter a name and description for the batch
3. Add year folder paths (one per line), e.g.:
   ```
   /Volumes/KAILUA PROJECTS/2023
   /Volumes/KAILUA PROJECTS/2024
   ```
4. Click **"Create Batch"**

### 3. Run the Scan

1. From the batch detail page, click **"Run Scan"**
2. The system will scan each folder for PIF files
3. Results will be stored in the database

### 4. Import CSV Results

If you have existing scan results in CSV format:

1. Click **"Import CSV"** from the dashboard
2. Upload your CSV file
3. Provide a batch name and description
4. Choose whether to update existing results
5. Click **"Import CSV"**

### 5. Set Up Scheduled Scans

1. Click **"New Schedule"** from the dashboard
2. Configure the schedule:
   - **Name**: Descriptive name for the schedule
   - **Frequency**: Daily, weekly, monthly, or manual
   - **Year Folders**: Paths to scan
   - **Active**: Enable/disable the schedule
3. Click **"Create Schedule"**

## CSV Format

The system expects CSV files with the following columns:

| Column | Description | Required |
|--------|-------------|----------|
| `container_dir` | Full path to the container directory | Yes |
| `folder_kind` | Type of folder (Business, Documents, etc.) | No |
| `status` | Scan status (ingested, skipped, error) | Yes |
| `reason` | Reason for status (ok, no_pif_found, error message) | No |
| `pif_file` | Full path to the PIF file if found | No |
| `files_count` | Number of files in the directory | No |
| `rows` | Number of rows in the PIF file | No |

### Example CSV:
```csv
container_dir,folder_kind,status,reason,pif_file,files_count,rows
/Volumes/KAILUA PROJECTS/2023/23-001 Hickam AFB Acoustical Testing/Business,Business,ingested,ok,/Volumes/KAILUA PROJECTS/2023/23-001 Hickam AFB Acoustical Testing/Business/PIFX 23-001_Revised 230405.xlsx,1,529
/Volumes/KAILUA PROJECTS/2023/23-001 Hickam AFB Acoustical Testing/Documents,Documents,skipped,no_pif_found,,,
```

## Management Commands

### Run Scheduled Scans

```bash
python manage.py run_pif_scans
```

### Run Specific Schedule

```bash
python manage.py run_pif_scans --schedule-id 1
```

### Force Run (ignore timing)

```bash
python manage.py run_pif_scans --force
```

## Integration with Billing System

The PIF scanner integrates with the billing system in several ways:

1. **Project Linking**: Scan results can be linked to existing projects
2. **PIF Data**: Extracted project information can be used to populate PIF forms
3. **Accounting Summary**: Project names from scan results appear in the accounting summary page
4. **Search**: Use the project search API to find PIF files by project

## File Structure

The scanner expects project directories to follow this structure:

```
/Volumes/KAILUA PROJECTS/
├── 2023/
│   ├── 23-001 Project Name/
│   │   ├── Business/
│   │   │   └── PIFX 23-001.xlsx
│   │   └── Documents/
│   └── 23-002 Another Project/
│       ├── Business/
│       └── Documents/
└── 2024/
    └── ...
```

## PIF File Patterns

The scanner looks for files matching these patterns:
- `PIF*.xlsx`
- `PIFX*.xlsx`
- `Project*Information*Form*.xlsx`
- `PIF*.xls`
- `PIFX*.xls`

## Database Models

### PIFScanBatch
Represents a batch of PIF scans with configuration and results.

### PIFScanResult
Individual scan results for each directory scanned.

### PIFScanSchedule
Scheduled scans for periodic execution.

## API Endpoints

### Project Search
`GET /billing/pif-scanner/api/project-search/?q=<query>`

Returns PIF scan results matching the search query.

## Troubleshooting

### Common Issues

1. **Permission Errors**: Ensure the application has read access to the project directories
2. **File Format Errors**: Some Excel files may not be readable due to format issues
3. **Path Issues**: Verify that the year folder paths are correct and accessible

### Logs

Check the Django logs for detailed error information when scans fail.
